Windows Agent — ساختار پوشه‌ها
=============================

C:\Users\alibatel\My Drive\Windows-Agent-DB\
├── User-Interface\      ← این پوشه: کد خود برنامه (app.py + run.bat)
├── Codes\               ← Arena کدهای جانبی را این‌جا می‌گذارد (job_*.py)
│   └── done\            ← کدهای اجراشده بعد از اجرا این‌جا می‌روند
├── out\                 ← نتیجه هر اجرا (job_xxx_result.txt)
├── ScreenShots\         ← عکس‌ها (نام جلالی)
└── logs\                ← گزارش‌های txt

نحوه استفاده
------------
1) روی run.bat در همین پوشه دوبار کلیک کن.
2) برنامه باز می‌شود؛ سه تب دارد: عملیات / آخرین تغییرات / کدها
3) در هدر می‌بینی: نسخه، هش کامیت، تاریخ جلالی و ساعت تهران ساخت
   همچنین دو چراغ: اینترنت و گوگل درایو
4) هر فایلی با نام job_*.py که Arena در پوشه Codes بگذارد،
   خود برنامه (در تب «کدها») شناسایی و اجرا می‌کند و نتیجه را در out می‌نویسد.

قوانین اجرای خودکار
--------------------
• فقط فایل‌هایی با پیشوند job_ و پسوند .py اجرا می‌شوند
• هر فایل فقط یک بار اجرا می‌شود
• فایل باید چند ثانیه بدون تغییر بماند (تا سینک کامل شود)
• حداکثر زمان اجرا: ۱۰ دقیقه
• دکمه «بررسی فوری» در تب کدها، پوشه را دستی بررسی می‌کند
