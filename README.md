# Windows Agent

ابزار ساده‌ی اتوماسیون دسکتاپ ویندوز با رابط کاربری گرافیکی.

نسخه فعلی: **۰.۳** — فقط دو دکمه، بدون هیچ پیچیدگی اضافه.

---

## قابلیت‌های فعلی

| دکمه | کار |
|------|-----|
| 📸 **باز کردن lmarena و گرفتن اسکرین‌شات** | سایت `lmarena.ai` را در یک پنجره جدید Google Chrome (تمام‌صفحه) باز می‌کند، **۵ ثانیه** صبر می‌کند تا صفحه لود شود و بعد اسکرین‌شات کامل صفحه را در **`C:\Users\alibatel\My Drive\Windows-Agent-DB\ScreenShots`** ذخیره می‌کند. |
| 📋 **گزارش برنامه‌های باز** | فهرست همه پنجره‌های قابل مشاهده ویندوز (نام برنامه، PID، عنوان پنجره) را می‌خواند، در کادر وضعیت نشان می‌دهد و یک فایل `open_apps_report_تاریخ.txt` در **`C:\Users\alibatel\My Drive\Windows-Agent-DB\logs`** ذخیره می‌کند. |

### ساختار پوشه‌های گوگل درایو

```
My Drive/
└── Windows-Agent-DB/
    ├── ScreenShots/   ← عکس‌ها  (lmarena_YYYY-MM-DD_HH-MM-SS.png)
    └── logs/          ← گزارش‌ها (open_apps_report_YYYY-MM-DD_HH-MM-SS.txt)
```

نام فایل اسکرین‌شات: `lmarena_YYYY-MM-DD_HH-MM-SS.png`

### اگر گوگل درایو در دسترس نباشد

اگر پوشه `My Drive` پیدا نشود (Google Drive برای ویندوز اجرا نشده باشد)،
برنامه خطا نمی‌دهد: در لاگ هشدار می‌دهد و فایل‌ها را موقتاً در
`Desktop\ScreenShots` و `Desktop\logs` ذخیره می‌کند.

نکته مهم: برنامه هرگز خود پوشه‌ی `My Drive` را نمی‌سازد؛ چون در آن حالت
یک پوشه‌ی محلی بی‌فایده ساخته می‌شد که هیچ‌وقت با گوگل sync نمی‌شد.

## نحوه اجرا

1. روی ویندوز، Python 3.9 یا بالاتر نصب باشد
   (مهم: هنگام نصب تیک **Add python.exe to PATH** را بزنید).
2. فایل **`run.bat`** را دوبار کلیک کنید.

همین. فایل bat خودش:

- پایتون را پیدا می‌کند،
- اگر کتابخانه `Pillow` نصب نباشد یک‌بار نصبش می‌کند،
- و برنامه را بدون پنجره سیاه کنسول (`pythonw`) اجرا می‌کند.

اگر برنامه بالا نیامد، فایل `error.log` کنار `app.py` را ببینید.

## ساختار فایل‌ها

```
Windows-Agent/
├── run.bat              ← همین را دوبار کلیک کنید
├── app.py               ← کل برنامه (رابط کاربری + اسکرین‌شات + گزارش)
├── requirements.txt     ← تنها پیش‌نیاز: Pillow
├── bridge/              ← پل Arena: اجرای کد از گوگل درایو
│   ├── START-BRIDGE.bat
│   ├── bridge_watcher.pyw
│   ├── README-BRIDGE.md
│   └── codes/           ← فایل‌های job_*.py این‌جا گذاشته می‌شوند
└── README.md
```

## پل Arena (اجرای کد بدون Pull)

با اجرای `bridge/START-BRIDGE.bat` یک ناظر کوچک در پس‌زمینه روشن می‌شود که
پوشه‌ی `bridge/codes` در گوگل درایو را تماشا می‌کند. هر فایل `job_*.py` که
آنجا گذاشته شود اجرا می‌شود و نتیجه در `bridge/out` نوشته می‌شود.
جزئیات کامل: [`bridge/README-BRIDGE.md`](bridge/README-BRIDGE.md)

## نکات

- اسکرین‌شات از **کل صفحه** گرفته می‌شود (همه مانیتورها)، پس پنجره کروم روی بقیه پنجره‌ها باز و نمایان می‌شود.
- اگر Chrome در مسیرهای معمول یا رجیستری پیدا نشود، لینک با مرورگر پیش‌فرض ویندوز باز می‌شود.
- زمان انتظار برای لود صفحه در بالای `app.py` قابل تغییر است:
  `PAGE_LOAD_SECONDS = 5`
- مسیرها در `app.py` قابل تغییرند:
  ```python
  DRIVE_BASE_DIR   = r"C:\Users\alibatel\My Drive\Windows-Agent-DB"
  SCREENSHOT_DIR   = DRIVE_BASE_DIR + r"\ScreenShots"
  REPORT_DIR       = DRIVE_BASE_DIR + r"\logs"
  FALLBACK_BASE_DIR = None   # None یعنی دسکتاپ
  ```
- گوگل درایو باید در حال اجرا باشد تا درایو `G:` (حالت File Stream) در دسترس باشد؛
  برنامه بعد از آپلود، خودش فایل را از طریق API گوگل درایو قابل خواندن می‌کند.
