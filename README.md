# Windows Agent

ابزار اتوماسیون دسکتاپ ویندوز، با رابط کاربری ساده.

نسخه فعلی: **۰.۹**

---

## ساختار ریپو (User-Interface)

```
Windows-Agent/
├── app.py          ← برنامه (رابط کاربری)
├── run.bat         ← اجرای برنامه
├── codes/          ← کدهایی که باید روی سیستم اجرا شوند (job_*.py)
└── version.txt     ← شماره نسخه؛ هر تغییر آن = نسخه جدید
```

## ساختار گوگل درایو (فقط دو پوشه)

```
My Drive\Windows-Agent-DB\
├── ScreenShots\    ← عکس‌ها
└── logs\           ← گزارش‌ها و نتیجه اجرای کدها
```

## ارتباط چطور برقرار می‌شود

1. Arena کد را در پوشه `codes/` ریپو کامیت می‌کند و `version.txt` را بالا می‌برد.
2. برنامه هر ۱۰ ثانیه `version.txt` را چک می‌کند (بسته zip ریپو، بدون کلید API).
3. اگر نسخه عوض شده باشد:
   - محتویات پوشه `codes/` جایگزین پوشه محلی `codes/` می‌شود.
   - اگر `app.py` تغییر کرده باشد، نسخه پشتیبان گرفته و برنامه ری‌استارت می‌شود.
   - کدهای جدید/تغییریافته اجرا می‌شوند.
4. نتیجه هر اجرا در `logs` گوگل درایو نوشته می‌شود و Arena آن را می‌خواند.

```
Arena → GitHub (codes/ + version.txt) → برنامه ویندوز → اجرا
                                   ↳ نتیجه → Google Drive/logs → Arena
```

## اجرا

1. پوشه برنامه را **محلی** نگه دار (مثلاً `C:\Windows-Agent`)، داخل گوگل درایو نه.
2. روی `run.bat` دوبار کلیک کن.

## قابلیت‌های برنامه

| دکمه | کار |
|---|---|
| 📸 اسکرین‌شات | سایت را در کروم باز می‌کند، ۵ ثانیه صبر، اسکرین‌شات در `ScreenShots` |
| 📋 گزارش | فهرست پنجره‌های باز ویندوز در `logs` |

سه چراغ وضعیت: اینترنت / گوگل درایو / گیت‌هاب
سه تب: عملیات / آخرین تغییرات / کدها

## نکته‌ها

- پروکسی سیستم ویندوز (مثل v2rayN) خودکار شناسایی و استفاده می‌شود.
- نام فایل‌ها با تاریخ جلالی و ساعت تهران است.
- نام کدهای قابل اجرا باید با `job_` شروع شود و پسوند `.py` داشته باشد.
