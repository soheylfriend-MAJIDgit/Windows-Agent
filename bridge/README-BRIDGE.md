# پل Arena (Arena Bridge)

با این مکانیزم، Arena می‌تواند بدون GitHub و بدون Pull، کد را برای اجرا روی
کامپیوتر ویندوزی بفرستد. کاربر فقط یک بار ناظر را روشن می‌کند.

---

## چطور کار می‌کند

```
Arena  →  codes/job_xxxx.py  →  Drive sync  →  watcher اجرا می‌کند
                                                        ↓
Arena  ←  out/job_xxxx_result.txt  ←  Drive sync  ←  نتیجه
```

---

## ساختار پوشه در گوگل درایو

```
C:\Users\alibatel\My Drive\Windows-Agent-DB\bridge\
├── START-BRIDGE.bat        ← دوبار کلیک: ناظر را در پس‌زمینه اجرا می‌کند
├── bridge_watcher.pyw      ← خود ناظر
├── README-BRIDGE.md        ← این راهنما
├── codes\                  ← ورودی: Arena این‌جا job_*.py می‌گذارد
│   └── done\               ← فایل‌های اجراشده بعد از اجرا این‌جا منتقل می‌شوند
├── out\                    ← خروجی هر اجرا: job_xxxx_result.txt
├── status.txt              ← نبض ناظر (زمان آخرین بررسی و تعداد کارها)
├── watcher.log             ← گزارش کامل اتفاقات
├── state.json              ← حافظه: چه فایل‌هایی قبلاً اجرا شده‌اند
└── PAUSE.txt               ← اگر این فایل را بسازی، اجرا متوقف می‌شود
```

> این پوشه در ریپو فقط نسخه‌ی مرجع است. نسخه‌ی اجرایی روی گوگل درایو
> قرار می‌گیرد و همان جاست که ناظر کار می‌کند.

---

## نحوه استفاده

1. یک بار روی **`START-BRIDGE.bat`** دوبار کلیک کن.
2. تمام. ناظر هر ۳ ثانیه پوشه `codes` را نگاه می‌کند.
3. Arena فایل `job_xxxx.py` را در `codes` می‌گذارد → ناظر اجرا می‌کند →
   نتیجه در `out` نوشته می‌شود → Arena از گوگل درایو می‌خواندش.

ناظر پنجره ندارد (با `pythonw` اجرا می‌شود). برای اطمینان از زنده بودنش،
فایل `status.txt` را باز کن؛ زمان آخرین بررسی در آن است.

---

## قوانین ایمنی پیاده‌شده

| قانون | توضیح |
|---|---|
| فقط `job_*.py` | فایل‌های دیگر حتی اگر در پوشه باشند اجرا نمی‌شوند |
| فقط یک بار | هر فایل بر اساس `state.json` فقط یک بار اجرا می‌شود |
| صبر برای سینک | فایل باید چند ثانیه بدون تغییر بماند تا اجرا شود (نصفه اجرا نمی‌شود) |
| محدودیت زمان | هر کار حداکثر ۱۵ دقیقه |
| توقف فوری | ساخت فایل `PAUSE.txt` همه اجراها را متوقف می‌کند |
| ثبت کامل | زمان، هش SHA-256، خروجی و خطاها در `out` و `watcher.log` |

نکته امنیتی: این مکانیزم اجازه اجرای کد روی سیستم تو را می‌دهد؛ پس امنیت
حساب گوگل مهم است. دو مرحله‌ای (2FA) را روشن نگه دار. اگر خواستی ناظر را
کامل خاموش کنی، در Task Manager فرایند `pythonw.exe` را ببند یا `PAUSE.txt` بساز.

## تنظیمات قابل تغییر (متغیرهای محیطی)

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `BRIDGE_BASE` | `C:\Users\alibatel\My Drive\Windows-Agent-DB\bridge` | مسیر ریشه |
| `BRIDGE_POLL` | `3` | فاصله بررسی پوشه (ثانیه) |
| `BRIDGE_SETTLE` | `3` | چند ثانیه فایل ثابت بماند تا اجرا شود |
| `BRIDGE_MAX_RUNTIME` | `900` | حداکثر زمان هر کار (ثانیه) |

## اولین تست

فایل `codes\job_0001_hello.py` از قبل گذاشته شده است. بعد از اجرای
`START-BRIDGE.bat` چند ثانیه صبر کن و بعد این فایل را ببین:

```
out\job_0001_hello_result.txt
```

اگر ساخته شد، پل برقرار است و از این به بعد Arena می‌تواند کد بفرستد،
نتیجه را بخواند و اصلاح کند — بدون هیچ کار اضافه‌ای از طرف تو.
